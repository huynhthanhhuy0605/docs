Students and teachers can use **Image to Frames Pro free**. Once you have your student code, redeeming it takes about a minute: open the app in Canva, go to the student page, and apply the code at checkout.

<Note>
Don't have a code yet? Get one from the [Qrdy Student Pack](https://qrdyai.com/studentpack) first, then come back to this guide.
</Note>

## Redeem your student code in 3 steps

<Steps>
<Step title="Open Image to Frames in Canva">
On your code card, click **Open in Canva & Use Code**. You're taken straight to the Image to Frames app inside Canva.

<Frame>
<img src="/images/image-to-frames/student/image-to-frames-student-code-open-in-canva.png" alt="Image to Frames student discount code card with the Open in Canva & Use Code button" style={{maxHeight: '50vh', width: 'auto', height: 'auto', objectFit: 'contain'}} />
</Frame>

<Tip>
You can also open Canva, go to **Apps** in the left sidebar, search for **Image to Frames**, and open it.
</Tip>

<Warning>
Codes expire. Check the expiry date on your card and redeem before it runs out.
</Warning>
</Step>

<Step title="Click “Free for students & teachers”">
In the app panel, find the line **Free for students & teachers – learn more** under *Image to Frame Pro* and click **learn more**.

<Frame>
<img src="/images/image-to-frames/student/image-to-frames-free-for-students-teachers-canva-app.png" alt="Image to Frames app panel in Canva showing the Free for students & teachers link" style={{maxHeight: '50vh', width: 'auto', height: 'auto', objectFit: 'contain'}} />
</Frame>

This opens the **Image to Frames for students** page.

<Frame>
<img src="/images/image-to-frames/student/image-to-frames-for-students-enter-code-page.png" alt="Image to Frames for students page with Form Submission and Enter Code buttons" />
</Frame>
</Step>

<Step title="Enter your code at checkout">
Click **Enter Code**. On the checkout page, scroll to the bottom, paste your code into the **Discount code** field, and click **Apply**. The total drops to $0 — finish checkout and Pro is unlocked.

<Frame>
<img src="/images/image-to-frames/student/image-to-frames-student-discount-code-checkout.png" alt="Checkout page with the student code entered in the discount code field and the Apply button" style={{maxHeight: '50vh', width: 'auto', height: 'auto', objectFit: 'contain'}} />
</Frame>

<Check>
Done! Go back to Canva, click **Restart Image to Frame** in the app panel, and start creating with Pro.
</Check>
</Step>
</Steps>

## Quick checklist

- [ ] Clicked **Open in Canva & Use Code** (or found Image to Frames in Canva Apps)
- [ ] Clicked **Free for students & teachers – learn more**
- [ ] Clicked **Enter Code** and applied your code at the bottom of checkout
- [ ] Restarted the app in Canva

## Troubleshooting

<AccordionGroup>
<Accordion title="My code says it's invalid or expired">
Each code has an expiry date shown on your code card. Copy the code again using the **Copy** button to avoid typos or extra spaces. If it has expired, request a new one from the [Student Pack page](https://qrdyai.com/studentpack).
</Accordion>

<Accordion title="The total didn't drop to $0">
Make sure you clicked **Apply** after pasting the code. The discount only shows after it's applied.
</Accordion>

<Accordion title="Pro isn't active in Canva after checkout">
Click **Restart Image to Frame** in the app panel. If Pro still doesn't show, close and reopen your Canva design.
</Accordion>
</AccordionGroup>
